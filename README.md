## Descripción del proyecto

RentaCar Express es una aplicación de escritorio desarrollada en C# que permite registrar alquileres de vehículos y calcular automáticamente los costos correspondientes.

## Funcionalidades

- Registro de clientes y vehículos.
- Selección de fecha de salida y días de alquiler.
- Selección de seguro básico o completo.
- Opción de GPS.
- Descuento del 15 % para clientes corporativos.
- Entrega a domicilio con un costo adicional de RD$500.
- Cálculo automático del ITBIS del 18 %.
- Cálculo del total a pagar.
- Registro de alquileres en una lista.
- Opciones para limpiar el formulario y salir del sistema.
